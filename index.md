# redapp ff_backup

redapp ff_backup is a personal backup utility operated by the account owner. It uses rclone on the owner's main server to back up logs and reports from the owner's redapp servers to the owner's Google Drive.

The utility is used only by the account owner. This website contains information about the utility; it does not store backup files.
